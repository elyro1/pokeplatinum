# Field night lights: which materials glow, fade or mirror lights at night,
# and the light sources placed in the world.
#
# The game reads this file from its folder when it starts and again from
# Graphics > Reload light table, so edits apply while playing. A copy is
# built in and used when the file is missing; a file with errors is
# reported in the Graphics panel and the previous table is kept.
#
# Lines (# starts a comment; values are separated by spaces):
#
# material NAME ROLE [bloom=B] [intensity=I] [map=MAP] [prop=N|land]
#   NAME matches a model's material name, and longer names that continue
#   with "_", such as a lightmap suffix "_lm4" (so "light" also matches
#   "light_a"). The first matching line wins, so lines scoped to a map or
#   prop, and longer names, go before general ones.
#   ROLE is one of:
#     shadow          authored ground shadow; fades at night
#     painted_shadow  shadow disc painted into a grass tile; fades at night
#     tree            tree atlas whose stump cells paint the tree's shadow
#     puddle_ground   path or sand that collects puddles in rain
#     window          glass that glows warm at night
#     source          light fixture that keeps its own colors
#     lamp            lamp mesh whose near-white glass emits
#     light_bar       only the brightest texels emit, inside white trim
#     neon            shared texture whose saturated bulbs emit
#     keyed_window    shared texture whose colored panes glow warm
#     beacon          lighthouse lantern; pulses with its beams
#     screen          video screen; keeps its colors and flickers gently
#     emblem          shared texture whose yellow emblem emits
#     lava            glows in its own colors by day too, pulsing slowly
#     water           water surface; mirrors lights at night
#   bloom: halo strength, at most 3 (default 0). Windows and lamps use 2,
#     large signs 0.85 so their halo does not swamp the building.
#   intensity: how strongly the surface lights up (default 1).
#   map: only on this map (a map header name without MAP_HEADER_).
#   prop: only on this prop model, or "land" for the map's land mesh.
#
# lamp KIND MAP X Y Z [aim=A] [width=W] [deck=D]
#   A light in a land mesh, which is not a prop, at world position X Y Z.
#   KIND street: a lamp lighting the pavement around it.
#   KIND downlight: a Cycling Road light whose head reaches over the road;
#     aim is the x offset of the lit patch on the road from the head, width
#     the half width of its pool, deck the patch's height at the head's z
#     (0: no painted patch).
#
# prop_light PROP KIND X Y Z
#   A light on every instance of a prop model, offset from its origin.
#   KIND window: a lit window, with a pool in front of it.
#   KIND center: a Pokémon Center logo, lighting the entrance.
#   KIND beacon: Vista Lighthouse's lantern and its turning beams.
#
# day_emission MAP
#   Something glows by day on this map (lava), so glow and bloom run then.
